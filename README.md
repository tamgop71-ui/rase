# RAZE RUSSIA VK BOT — ULTIMATE EDITION (v3.0)

Полностью пересобранный и расширенный бот для управления беседами, сетками чатов (Unities), экономикой, государствами, браками, тикетами и автомодерацией ВКонтакте.

## Главные особенности
- **Все префиксы команд**: работают `!`, `/` и `.` (например: `!помощь`, `/help`, `.профиль`).
- **Двуязычность (RU + EN)**: каждая команда понимает русское и английское написание.
- **Гибкая система приоритетов (0 — 100 + Супер-доступ `/addws`)**:
  - `0` — Участник
  - `20` — Помощник
  - `40` — Модератор
  - `60` — Администратор
  - `80` — Ст. администратор
  - `100` — Владелец беседы
  - `/addws` (`OWNER_VK_ID`) — Создатель бота / Супер-доступ во всех беседах.
- **Объединения бесед (Unities)**: глобальные баны (`!gban`), кики (`!gkick`), роли (`!grole`), ники (`!gsnick`) и вызовы (`!gzov`) сразу по всей сетке чатов.
- **Игровая система и РП**: баланс, казино (`!казино 5к`), переводы (`!перевод`), работы (`!работа`), дуэли (`!дуэль`), государства (`!гражданство`, `!страны`), браки с инлайн-кнопками (`!брак`, `!развод`, `!браки`) и РП-действия.
- **Система репортов / тикетов**: `/report`, `!reports`, `!getreport`, `!getdialog`, `!reportedit`.
