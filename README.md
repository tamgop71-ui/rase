# RAZE RUSSIA VK BOT

Чистая сборка ВК-бота на PHP 8.2 (Callback API) с поддержкой удаленной базы данных MySQL и деплоя на BotHost через GitHub.

## Структура файлов
- `bot.php` — основной обработчик запросов VK Callback API.
- `config.php` — конфигурация через переменные окружения и подключение к БД (PDO).
- `cron.php` — регламентные задачи очистки устаревших логов.
- `database_update.sql` — SQL-скрипт создания структуры БД и прав администратора.
- `Dockerfile` — файл контейнеризации для развертывания на BotHost / Docker.
- `env.example` — пример переменных окружения.
