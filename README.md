# RAZE RUSSIA VK BOT — v5.0 IDEAL EDITION

Максимально быстрый, стабильный и функциональный чат-менеджер ВКонтакте на PHP 8.2 + MySQL 8.

## Ключевые оптимизации скорости (v5.0)
- **OPcache + 4 параллельных воркера** (`PHP_CLI_SERVER_WORKERS=4`) в `Dockerfile`.
- **Постоянное подключение к удаленной БД** (`PDO::ATTR_PERSISTENT`) с авто-переподключением.
- **HTTP/2 Keep-Alive cURL** для VK API — убирает повторные TLS-рукопожатия.
- **Объединённый 1-запросный контекст** (`ensureUserAndMember`) и пакетная предзагрузка пользователей (`preloadUsers`) для мгновенной работы `!топ`, `!админы`, `!онлайн`, `!warnlist`, `!banlist`.
- **Файловый анти-флуд** в `/tmp` без лишних запросов к БД.
