# RAZE RUSSIA VK BOT — v6.0 TURBO

Сверхбыстрый чат-менеджер ВКонтакте на PHP 8.2 (OPcache + JIT + 8 воркеров + фоновый демон `worker.php`).

## Что нового в v6.0 TURBO
- **Ускорение до 3x**: 1-запросный контекст с проверкой мута, multi-table UPDATE, `/tmp` кэш ролей/белого списка/фильтров/триггеров, вынос таймеров и напоминаний в отдельный фоновый процесс `worker.php`, OPcache JIT + 8 воркеров.
- **Белый список ссылок (`!whitelist`)**: автомод пропускает форум, группу ВК и разрешённые домены.
- **Напоминалки (`!напомни`)**: личные и чатовые, приходят точно в срок через `worker.php`.
- **Для пользователей**: кейсы (`!кейс`), промокоды (`!промо`), ежедневные квесты (`!квесты`), опросы на кнопках (`!опрос`), режим AFK (`!афк`).
- **Для админов**: анти-слив (`!антислив`), фильтр слов (`!фильтр`), автоответчик (`!триггер`), KPI стаффа (`!актив`), создание промокодов (`!создатьпромо`).
