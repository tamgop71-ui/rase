# RASE RUSSIA VK BOT

Высокоскоростной чат-менеджер ВКонтакте на PHP 8.2 (OPcache + JIT + 8 воркеров + фоновый демон `worker.php` с пакетной записью статистики).

## Основные возможности
- **Скорость отклика:** zero-DB fast-path для `!пинг`, `/tmp`-кэш настроек чата и ролей с мгновенной инвалидацией, отложенная пакетная запись статистики через `worker.php`, HTTP/2 Keep-Alive для VK API.
- **Модерация и защита:** роли (0–100 + `/addws`), муты/варны/баны, объединения (`!unity`), анти-слив (`!антислив`), анти-рейд (`!антирейд`), авто-капча при входе (`!капча`), анти-стикер (`!антистикер`), антифлуд, медленный режим (`!слоумод`), автомодерация с белым списком ссылок (`!whitelist`), фильтр слов (`!фильтр`), очистка (`!очистить`), журнал действий (`!логи`), KPI стаффа (`!актив`), рассылка по объединению (`!гобъявление`).
- **Удобство:** напоминания в чат и ЛС (`!напомни`), опросы на кнопках (`!опрос`), режим AFK (`!афк`), калькулятор (`!кальк`), статус в профиль (`!био`), автоответчик (`!триггер`), заметки (`!заметки`), тикеты (`/report`).
- **Экономика и игры:** баланс, банк, ограбления и щиты, магазин привилегий (`!магазин`), семьи/кланы (`!клан` с общаком и управлением), кейсы (`!кейс`), промокоды (`!промо`), ежедневные квесты (`!квесты`), серия бонусов (`!бонус`), блэкджек (`!21`), казино, слоты, рулетка, монетка, дуэли, государства, браки и РП.

## Команды супер-доступа (/addws)
- `/sysban [ID] (дни) (причина)` / `/sysunban [ID]` — глобальный бан и кик из всех бесед с авто-киком при попытке входа.
- `/syskick [ID]` / `/sysmute [ID] [мин]` — глобальный кик и глобальный мут по всем беседам.
- `/sysrole [приоритет/название]` (или `/sysrole all [роль]`) — выдача себе любой роли.
- `/giverub [ID] [сумма]` (или `/giverub [сумма]` себе) — безлимитная выдача/списание рублей.
- `/givesoo [ID] [кол-во]` (или `/givesoo [кол-во]` себе) — выдача/списание сообщений.
- `/sysinfo` — полная сводка по боту, памяти и БД.
- `/sysbroadcast [текст]` — быстрая параллельная рассылка во все беседы.
