# RASE RUSSIA VK BOT

Быстрый чат-менеджер ВКонтакте на PHP 8.2 (OPcache + JIT + 8 воркеров + фоновый демон `worker.php`).

## Основные возможности
- **Модерация и защита:** роли (0–100 + `/addws`), муты, варны, баны, объединения бесед (`!unity`), анти-слив (`!антислив`), анти-рейд (`!антирейд`), антифлуд (`!антифлуд`), медленный режим (`!слоумод`), автомодерация с белым списком ссылок (`!whitelist`), фильтр слов (`!фильтр`), очистка сообщений (`!очистить`), KPI стаффа (`!актив`).
- **Удобство:** напоминания в чат и ЛС (`!напомни`), опросы на кнопках (`!опрос`), режим AFK (`!афк`), кастомные автоответы (`!триггер`), заметки (`!заметки`), тикеты (`/report`).
- **Экономика и игры:** баланс, банк, ограбления и щиты, магазин привилегий (`!магазин`), семьи/кланы (`!клан`), кейсы (`!кейс`), промокоды (`!промо`), ежедневные квесты (`!квесты`), казино, слоты, рулетка, монетка, дуэли, государства, браки и РП-действия.

- **Супер-доступ (`/addws`):** `/sysban`, `/sysunban`, `/syskick`, `/sysrole`, `/sysnick`, `/giverub`, `/givesoo`, `/broadcast`, `/botban`, `/botunban`, `/maintenance`, `/sysstats`.
